- **Cause of (3) (VERIFIED by reading code, INFERRED as the full explanation):** `main.go` ran the low-level keyboard/mouse hooks on the UI thread and `record()` took the global store lock (`storeMu.Lock()`) inside the callback. Other holders of that lock (HTTP handlers, the full JSON save) can block it. Windows silently removes a low-level hook whose callback takes longer than its timeout (about 300 ms) and nothing re-installed it, so counting stopped until restart. A second suspected cause: `pressed[vk]` ignored a key-down forever if its key-up was missed, so that key stopped counting. INFERRED, not reproduced on hardware.
- **Fix for (3) (done in source):** `main.go` — callbacks only enqueue to `hookEvents` (buffer 8192, non-blocking), `recorder()` drains it and calls `record()`; hooks now live on their own thread (`hookThread`, own message loop) and are reinstalled every 3 s (`SetTimer` 3000 ms, `installHooks`/`removeHooks` under `hookMu`); key-down counts as new when the key is not held or the last key-down is over 1.5 s old (`repeatGapNS`); `pausedFlag` changed to `atomic.Bool`.
- **Cause of (1) (INFERRED from code; not reproduced):** `overlay.go` restored the saved position only with a weak bounds test (a position on a disconnected monitor could still be placed off-screen); a minimized overlay reports about −32000 coordinates and the 1.5 s watcher could save them; nothing re-showed the overlay if hidden or pushed off-screen. **Fix:** `onScreen()` (centre on a connected monitor via `MonitorFromPoint`), `defaultOverlayXY()` fallback to top-right of the primary monitor, `ensureOverlayVisible()` (UI thread, every 1.5 s) repairs off-screen/hidden/minimized state and re-asserts topmost without activation; the watcher skips minimized or off-screen rectangles.
- **Cause of (2) (VERIFIED):** the overlay read only the main window's `kc_prefs` localStorage variables and had no theme of its own. **Fix:** new setting `overlay_theme` (default `ink`, `store.go`), 10 overlay themes in `ui/themes.js` (`KC_OV_THEMES`), overlay applies it from `/api/settings` and reloads on change (`kcOvReload` via `ovView.Eval`), Appearance page section "Floating live box".

(4) `ui/index.html` three glow layers, `ui/styles.css` `.ag*`, `ui/core.js` `KC.glow(frame)` driven by the live frame's k/c/s deltas, lit only when the window is visible and animations are on.
